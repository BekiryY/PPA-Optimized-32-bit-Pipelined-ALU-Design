This is a testbench for the ALU design.
ADDER32_FAST_TB     --> Testbench of pipelined adder unit only
ALU_FAST_TB         --> Testbench of pipelined ALU unit only
ALU_LPnIDLE_TB      --> Testbench of pipelined ALU unit in LP and IDLE mode
ALU_Loose_TB        --> Testbench of pipelined ALU unit with input are valid %20 of the time
LOGIC_BLOCK_TB      --> Testbench of logic_block only
MULT32_FAST_TB      --> Testbench of pipelined multiplier unit only
SHIFTER_TB          --> Testbench of shifter unit only
